## 🚀 What it does

This extension is a modern alternative to the original **RespImageLint** bookmarklet, powered by its original core logic. Due to modern browser restrictions or strict user privacy settings, bookmarklets can sometimes be blocked or restricted. This extension serves as a seamless workaround for that problem.

Instead of hunting for a bookmark, simply click the extension icon in your browser toolbar to execute the exact same audits instantly.

## ✨ Features

* **⚡ One-Click Audits:** Run comprehensive checks on responsive images (`srcset`, `sizes`, and `<picture>` elements) instantly with a single click.
* **🛡️ Bypass Restrictions:** Works reliably even when strict privacy extensions or browser security policies block traditional bookmarklets.
* **🔍 Detailed Feedback:** Identifies common pitfalls, missing attributes, and optimization opportunities in your markup.
* **🧩 Lightweight & Fast:** Built with performance in mind, keeping your browser fast and responsive.

## 📦 Installation & Setup

### Option 1: Chrome Web Store (Recommended)
You can easily install the extension directly from the official [Chrome Web Store]().

### Option 2: Manual Installation (Developer Mode)
If you prefer to install it manually:

1. Download the latest release archive (`.zip`).
2. Unzip the downloaded archive into a local folder.
3. Open Google Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode** by clicking the toggle switch in the top-right corner.
5. Click the **Load unpacked** button in the top-left and select your unzipped folder.
6. Done! ✅
